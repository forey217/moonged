# MoonGED 项目申报书

1．项目名称：MoonGED。

2．项目简介：MoonBit 原生 GEDCOM 7 家谱数据交换与校验库。面向家谱软件导出文件，提供完整文档读写、标准结构和类型检查、家庭关系查询及错误定位。SDK、命令行和中文本地工作台共用同一 MoonBit 核心，只依赖标准库。

3．项目方向与通用性：数据交换基础工具。0.2.0 按官方 GEDCOM 7.0.18 实现第 1–3 章的文本容器、完整标准结构表、全部标准载荷类别及可机械判定的跨记录规则：179 种结构、1,379 种父子组合、12 组枚举，覆盖必填项、单例、引用目标及四种标准历法。未知扩展保留并提示外部语义未评估；不将词法通过解释为史料真实性证明。

4．三个完整使用场景：

档案交换：输入含人物、家庭、史料、共享备注、媒体路径和翻译的 UTF-8 家谱文件，经整份 Document 读写后交给下游软件；不经过人物字段白名单重建，保留顺序、指针和未知结构。

导入或持续集成检查：输入待接收文件，检查字段位置、重复单例、非法枚举、日期类型及跨记录一致性；输出行号、错误代码和关联行，修复后再次检查。家庭缺少反向链接、来源与备注互引成环均有明确失败案例。

MoonBit 应用接入：安装模块后读取人物、查询祖先和家庭路径，保留收养等限定；整理标识时同步更新真实指针，提取完整记录的引用闭包。日期转换覆盖 Gregorian、Julian、Hebrew 和法革历历史区间，扩展历法和超大年份保留并提示计算边界。

5．核心功能与验证：0.2.0 已完成上述交付，新增类型/枚举/日期和跨结构语义检查。57 个工作区测试和 11 个 Node 测试通过；包含从官方 YAML 独立提取的 2,422 个符合性正反案例、与 pyluach 2.3.0 对照的 1,040 个希伯来历边界向量，以及 36 份文件的独立解析器往返核对。完整范围、原始报告和复现命令见 docs/semantic-conformance.md；不支持第 4 章 GEDZIP、旧版转换、联网认证及生产采用声明，测试不等同第三方认证。

6．项目性质：原创 MoonBit 实现；按官方标准开发，没有移植外部解析器。运行时模式表由固定版本官方数据生成，独立工具仅用于测试。
