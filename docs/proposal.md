# MoonGED 项目申报书

1．项目名称：MoonGED。

2．项目简介：家谱软件交换数据常用 GEDCOM 文件，文件中的人物、家庭、史料通过标识互相引用。MoonGED 用 MoonBit 读取、审查和写出 GEDCOM 7，提供家庭关系查询接口，便于其他项目导入家谱数据、发现断链并继续加工。

3．项目方向与通用性：数据处理、可复用基础工具库。核心只依赖 MoonBit 标准库，公开人物、家庭、事件、日期和引用模型；Node 命令行、浏览器工作台及独立 MoonBit 模块共同调用核心，使用者不必接入某个家谱网站或框架。

4．至少三个完整预期场景：

- 家谱软件导入：输入 UTF-8 GEDCOM 7 文件，读取人物、家庭、多行备注及扩展字段，进行引用检查，再导出 GEDCOM 或人物 CSV；导出文件用独立解析器核对数据语义。
- 档案质量审查：批量文件进入 CI，定位重复标识、悬空引用、日期异常、缺少双向链接或关系环路，生成含行号的报告；有审查错误时命令行返回非零状态，维护者据此修正原始记录。
- MoonBit 应用接入：独立项目安装工具库，按人物标识查询祖先、后代和最短家庭关系路径，保留收养等限定及史料引用；按引用闭包提取记录或同时重命名标识与引用，导出后继续使用。

5．拟实现的核心功能及进度：已实现受限解析、增量 UTF-8 读取、规范化写出、所列审查规则、人物/家庭/事件视图、日期范围比较、关系查询、记录提取和标识重映射，提供网页、CLI 与独立接入样例。39 个 MoonBit 工作区测试、4 个 CLI 进程测试通过；33 份合成文件的节点及导出语义与独立解析器一致，参考 schema 验证报错为 0。后续补充真实软件导入反馈。范围为 GEDCOM 7 UTF-8 文本；不宣称完整标准验证，不支持 GEDZIP、旧版编码转换或网络媒体读取，关系不等同于生物亲缘。目前没有生产采用记录。

6．项目性质：原创项目，依据 FamilySearch GEDCOM 7 规范实现。2026 年 10 月 13 日更新的 Mooncakes 索引中检查了 2,978 个模块，未检出 GEDCOM 同类库；搜索有收录边界，不能据此断言唯一。

7．参考项目与许可证：本项目 MIT；规范见 https://gedcom.io/specifications/FamilySearchGEDCOMv7.html 。独立核对参考 gedcom7code/js-gedcom（MIT/Unlicense）及官方 GEDCOM-registries，保留来源与固定版本，不将参考实现包装成 MoonBit 核心。

8．GitHub 仓库：https://github.com/forey217/moonged 。公开仓库提供可复现运行命令、合成样例、测试、CI、边界说明和有效开发提交记录。
