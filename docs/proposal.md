# MoonGED 项目申报书

1．项目名称：MoonGED。

2．项目简介：家谱软件常用 GEDCOM 文件交换人物、家庭和史料。MoonGED 用 MoonBit 读取整份 GEDCOM 7 UTF-8 文本，保存结构、原始载荷与引用，再写出供后续使用，另提供关系查询和选定规则审查。核心只依赖标准库，CLI、本地网页和独立 MoonBit 模块调用同一核心。

3．项目方向与通用性：数据交换基础工具库。交付范围为 GEDCOM 7.0 文本容器与完整文档写出，覆盖七类标准记录及扩展子树，不按人物字段白名单丢弃其余内容。标准结构、枚举、数据类型和跨记录规则的审查仍是子集，不宣称完整标准验证。资源上限、符合性范围和案例见仓库 docs/text-conformance.md。

4．至少三个完整预期场景：

- 导入再导出：档案工作者输入含史料、媒体元数据及共享备注的文件，经完整 Document 规范化写出；保留节点层级、顺序、引用、文字和未知字段，再用独立解析器核对输出。媒体路径只保留，不读取文件。
- 多语言资料交换：输入多姓名、音译、翻译、不同日历及多行备注，保留 NAME 优先顺序、TRAN/LANG、PHRASE、空白和空指针；未支持日历提示后保留原文，不改历或补日期。BOM、换行及末尾换行按公开约定规范化。
- 应用接入与整理：独立 MoonBit 项目安装工具库，查询祖先、后代和家庭路径；改标识时同步改真实指针，普通文本不改。提取按整条记录及传递引用闭包进行，断开记录会被删除，超限报错；人物 CSV 是有损投影，不用于完整家谱往返。

5．核心功能与进度：0.1.1 已实现上述读写、增量 UTF-8、引用检查、日期子集、关系查询、标识重映射与提取。新增七个核心测试，修复共享备注/提交者记录、婚姻事件配偶年龄及扩展同名标签的误报。46 个工作区测试、9 个 Node 测试通过；36 份输入及输出节点与固定独立解析器一致，另有 BOM、CRLF、显著空白的逐字预期文件。参考 schema 检查无错误，保留其不理解部分数据类型和扩展的警告，不把测试视为全面认证。不支持 GEDZIP、旧版转换；暂无生产采用记录。

6．项目性质：原创实现，依据 FamilySearch GEDCOM 7。核心没有移植外部解析器，保留完整文档模型与查询投影的边界。

7．参考来源与许可证：本项目 MIT；规范 https://gedcom.io/specifications/FamilySearchGEDCOMv7.html 。独立核对使用 gedcom7code/js-gedcom（MIT/Unlicense）及官方 GEDCOM-registries，固定提交、来源和警告见 docs/interop.md，不作为运行时依赖。

8．GitHub 仓库：https://github.com/forey217/moonged ，含不少于 10 次有效开发提交。软件包为 forey217/moonged；仓库附安装说明、四份复杂输入、预期输出、回归测试和 CI。完整文本读写的语义保留及变换边界均有对应案例和复现命令。
